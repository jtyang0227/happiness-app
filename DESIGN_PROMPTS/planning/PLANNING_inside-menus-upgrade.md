# PLANNING — 4개 메뉴 내부 고도화 (Cosmos·SCRL 대조, 2026-10-20)

> 근거: `ANALYSIS_cosmos-scrl-public-features.md`(실화면 검증 전 — 외부 사이트 차단).
> 앞선 작업: `PLANNING_nav-consolidation.md`(메뉴 10개 → 탐색·내 작업·업무·모임 + ＋올리기).

## 1. 메뉴별 진단과 개선안

### 1.1 탐색 (`/explore`) — "둘러보다가 이어서 찾는" 흐름이 끊긴다
- 문제: 사진 하나가 마음에 들어도 다음 행동이 "같은 작가 사진"뿐이다. 다른 작가의 비슷한 사진으로 넘어갈 길이 없다.
  색감으로 고르는 작가가 많은데, 색은 *정렬*만 되고 *거를* 수 없다.
- **P0-A 비슷한 사진**: 사진 모달·상세 하단에 "비슷한 사진" 그리드(최대 12장).
  - 서버 `GET /api/photos/{id}/similar?size=12`(공개). 점수 = 장르 일치 3 + 색 분위기 일치 2 + 서브장르 겹침 1씩
    + 대표색 RGB 거리(가까울수록 최대 2) + 같은 비율 1. 후보는 같은 장르 또는 같은 색 분위기 사진 최근 300장(둘 다 없으면 최근 300장).
  - 다양성: 같은 작가는 최대 4장, 보고 있는 사진 자체는 제외. 점수 0은 빼고, 동점이면 최신순.
  - 한계: 실제 이미지 임베딩이 아닌 **메타데이터 유사도**다. 장르·색 정보가 없는 사진은 결과가 약하다.
- **P0-B 색 분위기 필터**: 장르 탭 아래 색 점 칩 11종(`MOOD_COLORS`) + "전체". URL `?mood=`로 공유. 서버 `colorMood` 파라미터 재사용.
- P1: 웹 무한 스크롤(IntersectionObserver, "더 보기" 버튼은 실패 시 재시도용으로 유지).
- P2: 자연어 의미 검색(임베딩), 반응 수 숨기기 작가 옵션.

### 1.2 내 작업 (`/series` + 프로필 저장함 보드) — 모은 것을 남에게 보여줄 수 없다
- 문제: 무드보드는 비공개라 의뢰인·협업자에게 "이런 느낌"을 보여 주려면 사진을 하나씩 보내야 한다.
- **P0-C 보드 공유 링크(보기 전용)**: 보드 상세에 "🔗 공유 링크 만들기" → 추측 불가능한 토큰 URL `/b/:token`(비로그인 공개).
  - `Moodboard.shareToken`(VARCHAR 32, nullable, UNIQUE). 링크 끄기 = 토큰 null(이전 링크 즉시 무효). 다시 만들면 새 토큰.
  - 공개 응답은 보드 이름·작성자 표시명·사진(삭제된 사진 제외)만. 회원 id·이메일 없음.
  - 공유 페이지는 Standalone(헤더 없음), 사진 정사각 그리드 + "Happiness에서 보기" 링크. 검색 엔진 노출 막음(`noindex`).
- P1: 보드 → "작업 노트로 만들기"(보드 사진으로 시리즈 생성).
- P2: 공개 보드 팔로우.

### 1.3 업무 (`/workspace`) — 의뢰인과 "느낌"을 맞추는 단계가 없다
- P1: 의뢰인 레퍼런스 보드 — 문의·예약에 보드 공유 링크를 붙이고, 의뢰인이 링크로 사진을 골라 담는 공동 보드(Cosmos 공동 편집).
  P0-C 공유 링크가 먼저 있어야 해서 다음 묶음으로 넘긴다.
- P2: 허브 카드에서 바로 처리(문의 읽음, 예약 확정) — 지금은 하위 탭으로 이동.

### 1.4 모임 (`/gatherings`) — 끝난 모임 앨범이 흩어진다
- P1: 모임 공동 보드 — 참여자 누구나 앨범 사진을 보드에 담는다(Cosmos 공동 클러스터).
- P2: 모임 앨범 → 캐러셀(아래 P0-D)로 바로 보내기.

### 1.5 편집 (＋올리기 → 에디터) — 한 장만 다듬고 끝난다 (SCRL 대조)
- 문제: 사진작가가 인스타그램에 작업을 올릴 때 가장 많이 쓰는 형식이 가로로 이어지는 캐러셀이다. 지금은 다른 앱(SCRL 등)으로 옮겨야 한다.
- **P0-D 캐러셀 분할 내보내기**: 내보내기 창 상단 "한 장 | 캐러셀" 전환.
  - 슬라이드 비율 4:5(1080×1350) / 1:1(1080×1080), 장 수 2~10, 여백 0~12%(슬라이드 높이 기준), 배경 흰색·검정·회색.
  - 원본: "지금 사진" 또는 "올린 사진 전부 이어 붙이기"(에디터에 2장 이상일 때). 보정·변형·오버레이를 적용한 결과를 그대로 쓴다.
  - 배치: 사진들을 같은 높이(슬라이드 높이 − 위아래 여백)로 맞춰 사진 사이 간격(여백과 같은 값)을 두고 한 줄로 놓는다.
    줄이 캔버스(장 수 × 슬라이드 폭)보다 길면 줄 전체를 줄이고, 짧으면 가운데 정렬한다.
  - 미리보기: 축소 캔버스 + 슬라이드 경계 점선 + 번호.
  - 다운로드: `파일명_01.jpg`…처럼 순서대로(브라우저 다중 다운로드 간격 300ms, 기존 "전체 다운로드"와 같은 방식).
  - 백엔드 변경 없음.
- P1: 레이아웃 템플릿(2분할·3분할·큰 1+작은 2), 분할 결과를 새 작업(시리즈)으로 업로드.
- P2: 슬라이드별 텍스트·스티커.

## 2. 수용 기준(AC)

- AC-1 사진 모달·상세에서 비슷한 사진이 최대 12장 보이고, 누르면 그 사진으로 바뀐다. 보고 있는 사진 자체는 없고 같은 작가는 4장 이하. 비로그인도 보인다.
- AC-2 색 분위기 칩을 누르면 그 분위기 사진만 보이고 URL에 `?mood=`가 남는다. 장르·검색어와 함께 걸린다. 빈 결과면 "조건 지우기".
- AC-3 보드 주인은 공유 링크를 만들고·복사하고·끌 수 있다. 끄면 이전 링크는 404. 링크는 비로그인으로 열리고 이름·사진만 보인다.
  남의 보드 공유 설정은 바꿀 수 없다(404).
- AC-4 에디터 내보내기 캐러셀 모드에서 비율·장 수·여백·배경을 바꾸면 미리보기가 바로 바뀌고, 다운로드하면 지정한 크기로 N장이 순서대로 받아진다.
  여러 장을 올렸으면 이어 붙이기를 고를 수 있다.

## 3. 트레이드오프

- 유사도는 임베딩 대신 메타데이터 점수. 추가 인프라 없이 오늘 동작하지만, 장르·색 정보가 비어 있는 사진엔 약하다.
  사진이 늘어 후보 300장 제한이 문제가 되면 먼저 깨진다 — 그때는 대표색을 HSV 버킷 컬럼으로 저장해 DB에서 거르는 게 다음 단계다.
- 공유 링크는 별도 공개 플래그 대신 토큰 하나로 처리한다. 토큰이 있으면 공개, null이면 비공개. 링크를 끄는 순간 이전 주소가 바로 죽는다.
- 캐러셀은 클라이언트 캔버스로 만든다. 서버 비용은 없지만, 10장 × 1080px 캔버스(최대 10800×1350)는 오래된 모바일 브라우저에서 메모리 한계에 가깝다. 장 수 상한을 10으로 둔 이유다.

## 4. 구현 결과 (2026-10-20)

- P0-A `GET /api/photos/{id}/similar`(공개) + `components/photo/SimilarPhotos.jsx` — 사진 모달(3열, 고르면 모달을 닫지 않고 그 사진으로 바뀜, 조회도 따로 기록)·사진 상세(6열, 모바일 3열).
- P0-B `PhotoBrowser`의 `MoodChips` — `?mood=`, 장르·검색어와 함께 걸림, 빈 결과의 "조건 지우기"가 장르·색·검색어를 모두 지움.
- P0-C `Moodboard.shareToken` + `PUT /api/moodboards/{id}/share` + 공개 `GET /api/moodboards/shared/{token}`, 웹 `MoodboardPage` 공유 패널, `pages/SharedBoardPage.jsx`(`/b/:token`, Standalone, `noindex`, 원작자 이름·포트폴리오 링크).
- P0-D `ExportModal` "한 장 | 캐러셀" — 미리보기(점선·번호), 지금 사진/이어 붙이기, 4:5·1:1, 2~10장, 여백 0~12%, 배경 3색, `파일명_01.jpg`… 순차 다운로드.
- 검증: 통합 테스트 2개 추가(34개 통과), 웹 빌드, Playwright(비로그인 색 필터·모달 유사 사진 전환, 공유 링크 생성·복사·비로그인 열람·끄기 후 404, 캐러셀 4장 1080×1350 다운로드), 페이지 에러 없음.
- 미구현(다음 묶음): 모바일 비슷한 사진·보드 공유, P1 항목 전부(웹 무한 스크롤, 보드 → 작업, 의뢰인·모임 공동 보드, 캐러셀 레이아웃 템플릿·묶음 업로드).
