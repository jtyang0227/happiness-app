# 기획서 — 로고 교체 + AKIRA 모션 컨셉 확장

작성일: 2026-08-23
담당: PM(기획) 역할
연관: `DESIGN_PROMPTS/design/DESIGN_PROMPT_akira-neo-tokyo-concept.md` (AKIRA Neo-Tokyo 색상 컨셉 계승)

---

## 1. 배경

사용자가 새 브랜드 로고 이미지(흑백 워드마크 마크)를 제공했다. 지금까지 앱 로고는 실제 이미지 없이
그라디언트 사각형 + 유니코드 `✦` 기호로 대체되어 있었다 — 임시방편에 가깝다. 실제 로고 자산이 생겼으니
이를 반영하고, 동시에 지난 AKIRA Neo-Tokyo 작업이 **색상 토큰 교체에 그쳤다**는 한계를 넘어 **모션**으로
확장한다. 아키라(1988)는 정지된 색상보다 "네온이 깜빡이는 도시", "빠르게 스치는 오토바이의 잔상" 같은
움직임 자체가 정체성이었다 — 지금 앱은 색은 아키라답지만 전부 정적이다.

## 2. 로고 자산 처리

원본 이미지(흰 배경 위 검정 워드마크)를 배경 제거해 두 버전으로 저장했다:
- `frontend/public/brand/logo-mark-white.png` — 흰색 마크, 투명 배경. 다크 배경(Header `#090909`,
  Login/SignUp 다크 히어로)에 사용.
- `frontend/public/brand/logo-mark-black.png` — 검정 마크, 투명 배경. 밝은 배경(favicon, 향후 라이트
  테마 컨텍스트)에 사용.

## 3. 로고 적용 범위

- `Header.jsx` 데스크탑 로고 — 현재 그라디언트 사각형+✦ → `logo-mark-white.png`로 교체.
- `LoginPage.jsx` / `SignUpPage.jsx` 히어로 아이콘 — 동일하게 이미지로 교체.
- `public/index.html` favicon — `logo-mark-black.png` 기반으로 교체.
- **모바일 하단 네비(BottomNav)의 "갤러리" 탭 아이콘 `✦`는 로고가 아니라 내비게이션 아이콘이므로
  이번 범위에서 건드리지 않는다** — 혼동해서 같이 바꾸면 안 됨.

## 4. AKIRA 모션 컨셉 — 무엇을 움직이게 할 것인가

정적인 컬러 토큰(레드+시안)에 아래 두 가지 모션을 더한다. **레드가 화면을 지배하지 않는다는 기존
원칙을 모션에도 그대로 적용한다** — 화면 전체가 흔들리거나 반짝이는 연출은 절대 금지, 로고·CTA 버튼 등
기존에 레드/화이트가 등장하던 바로 그 지점에서만, 아주 짧고 절제된 움직임으로 존재감을 준다.

1. **로고 진입 글리치**: 페이지 최초 로드 시 로고 이미지가 0.4~0.6초 동안 미세한 RGB 분리(chromatic
   aberration)와 수평 스캔라인 흔들림을 겪은 뒤 안정된 상태로 정착한다. 네온사인이 켜지는 순간을
   연상시키는 정도로 절제하며, 반복 재생하지 않는다(로드 1회성).
2. **프라이머리 버튼 호버 스피드라인**: `PrimaryBtn` 계열(로그인/회원가입 제출 버튼 등) 위에 마우스를
   올리면 버튼 표면을 가로지르는 대각선 스피드라인(하이라이트 스윽)이 0.5초 동안 한 번 스쳐 지나간다 —
   달리는 오토바이가 스쳐가는 잔상을 연상시키되, 버튼 내부에만 국한된다.

## 5. 유저 스토리

- 방문자로서, 로그인 화면에 들어왔을 때 로고가 "켜지는" 듯한 느낌을 받아 앱이 살아있다는 인상을 받고 싶다.
- 사용자로서, 버튼 위에 마우스를 올렸을 때 단순 색상 변화보다 조금 더 역동적인 반응을 느끼고 싶다.
- 접근성을 중시하는 사용자로서, 모션에 민감하다면 이 효과들이 자동으로 꺼지길 원한다.

## 6. 수용 기준 (AC)

- **AC1**: `Header.jsx`, `LoginPage.jsx`, `SignUpPage.jsx`의 로고 자리가 제공된 이미지 자산으로
  교체된다(그라디언트+✦ 유니코드 제거). BottomNav 갤러리 탭 아이콘은 변경되지 않는다.
- **AC2**: `public/index.html`의 favicon이 `logo-mark-black.png` 기반으로 교체된다.
- **AC3**: 로고에 최초 진입 시 1회성 글리치 애니메이션이 재생된다 — 무한 반복되지 않는다.
- **AC4**: 프라이머리 버튼 호버 시 스피드라인 스윕 애니메이션이 재생된다.
- **AC5**: 두 애니메이션 모두 `prefers-reduced-motion: reduce` 환경에서는 재생되지 않고 즉시 최종
  상태로 표시된다.
- **AC6**: 애니메이션이 레이아웃을 흔들거나(layout shift) 페이지 전체에 영향을 주지 않는다 — 요소
  내부 범위로 한정된다.
- **AC7**: `npm run build` 성공.
- **AC8**: 실제 브라우저에서 로그인/헤더/포트폴리오 화면을 확인해 로고와 애니메이션이 의도대로
  보이는지 스크린샷으로 검증한다.

## 7. 트레이드오프

- 외부 애니메이션 라이브러리(Framer Motion 등) 없이 순수 CSS `@keyframes` + inline style만 사용한다
  (CLAUDE.md 프론트엔드 규칙 준수).
- 로고 이미지가 JPEG 원본에서 배경 제거된 PNG라 벡터가 아니다 — 확대 시 계단현상이 보일 수 있다.
  향후 실제 SVG 원본을 받으면 교체 권장.
- 글리치 효과는 로드 1회성으로 제한해 반복 노출로 인한 피로도·산만함을 방지한다.
