# 출사 앱("인사이트 출사") 공개 기능 분석 → Happiness 반영안 (2026-11-23)

## 0. 분석 한계 (먼저 읽기)
- 앱스토어·웹 검색에서 "인사이트 출사"라는 이름의 앱을 **정확히 찾지 못했다**. 가장 비슷한 결과는 출사 장소 지도 앱
  **inSpotMap(인스팟맵, 개발사 '인스팟')** — 사진이 찍힌 장소를 지도에 핀으로 보여 주고, 친구·좋아요·신고·QR 공유·활동 지수 순위를 제공한다.
  그리고 당근 등의 **출사 모임** 패턴(정기 출사 일정, 장소 투표, 출사 후기·크리틱 공유, 인물 촬영 동의 규칙)도 참고했다.
- 클라우드 세션은 앱 실행·스크린샷이 불가능하다 → **공개 설명 기준이며 실화면 검증 전**. 앱 이름·링크가 다르면 이 문서의 1절만 고치면 된다.

## 1. 출사 앱의 핵심 기능 (공개 정보 기준)
| # | 기능 | 설명 |
|---|---|---|
| A | 출사 스팟 지도 | 사진 위치를 지도 핀으로, 내 주변 스팟, 스팟별 사진 모음 |
| B | 스팟 상세 | 대표 사진들, 찍기 좋은 시간대·계절, 주차·입장료 메모, 저장 |
| C | 출사 모임 | 정기 출사 일정, 장소 투표, 참가 신청, 초보 환영 표시 |
| D | 출사 후기·크리틱 | 모임 후 사진 + 짧은 후기, 서로 피드백 |
| E | 활동 지수·순위 | 올린 사진·스팟·좋아요로 점수, 순위 표시 |
| F | 공유·친구 | QR 공유, 친구 맺기, 친구 스팟 보기 |
| G | 안전·매너 | 오류 사진 신고, 인물 촬영 동의 규칙 |

## 2. Happiness 현재 상태와 대조
| 기능 | Happiness 현황 | 판단 |
|---|---|---|
| A 스팟 지도 | **없음.** `Photo`에 위치 필드 없음, 위치 좌표는 `Meet`(lat/lng)에만, 카카오 지도 SDK는 `MeetLocationPicker`에 이미 있음 | ✅ **반영 (P0)** — 기존 지도 컴포넌트 재사용 |
| B 스팟 상세 | 없음 | ✅ 반영 (P0, A와 함께) |
| C 출사 모임 | `gathering/` 모집·참여·대기자·피드·앨범·알림 **완비**. 좌표·장소 투표·정기 반복·초보 환영 없음 | ✅ **부분 반영 (P1)** — 모임에 스팟 연결 + "초보 환영" 태그 + 장소 투표 |
| D 후기·크리틱 | 모임 피드·댓글 있음, "크리틱 요청" 구분 없음 | ✅ 반영 (P1) — 게시물에 "피드백 원해요" 표시 |
| E 활동 지수·순위 | 없음 | ⚠️ **보류(P2)** — 포트폴리오·업무 앱 성격과 충돌, 좋아요 경쟁 유도. 대신 "이달의 출사 스팟" 큐레이션(기존 에디터 추천 패턴) |
| F QR·친구 | 팔로우·공유 링크 있음 | ✅ 작게 반영 (P2) — 포트폴리오·모임 QR (외부 라이브러리 없이 불가 → 보류 가능) |
| G 안전·매너 | 사진·댓글 신고, 차단 있음 | ✅ 반영 (P1) — 모임 생성 시 "인물 촬영 동의" 체크·모임 규칙 고정 문구 |

## 3. 적용하면 안 되는 것
- **사진 원본의 GPS 자동 공개 금지.** EXIF 좌표를 그대로 노출하면 집·작업실 위치가 드러난다 → 위치는 작가가 **직접 고른 스팟(공공 장소)** 만, 정밀도는 스팟 단위.
- 녹음·백그라운드 위치 권한(심사 리스크, 앱 심사 대응에서 막아 둠) — 현재 위치는 "내 주변 보기" 버튼을 눌렀을 때 1회만.
- 순위·점수 게임화 — 사용자 가치(일 받기)와 무관, 어뷰징·신고 증가.
- 다른 앱의 이름·로고·화면 복제.

## 4. 우선순위
- **P0 출사 스팟**: `spot/` 패키지(Spot, PhotoSpot 연결), 사진 등록 시 스팟 선택(선택), 둘러보기 "스팟" 탭(지도+목록), 스팟 상세.
- **P1 모임 연결**: 모임 ↔ 스팟, 초보 환영·인물 동의 표시, 장소 투표(후보 2~5개, 마감 전까지), 게시물 "피드백 원해요".
- **P2**: 이달의 스팟 큐레이션(어드민), 모바일 스팟 지도, 시간대 메모(골든아워 계산은 날짜·좌표만으로 클라이언트 계산 가능).

## 5. 수용 기준(요약)
- AC1 사진에 스팟을 붙이지 않아도 기존 등록이 그대로 동작한다.
- AC2 스팟 좌표는 위도 -90~90·경도 -180~180 검증, 같은 이름·200m 이내 중복 생성 시 기존 스팟 제안.
- AC3 스팟 목록·상세는 공개, 생성·수정은 로그인, 수정·삭제는 만든 사람/관리자(IDOR 403).
- AC4 지도 키(`REACT_APP_KAKAO_MAP_KEY`)가 없으면 목록 화면으로 동작(`MeetLocationPicker`와 같은 fallback).
- AC5 사진 EXIF GPS는 서버에 저장하지 않는다.
- AC6 `CoreFlowIntegrationTest`에 스팟 생성·중복 제안·IDOR·공개 조회 테스트.
