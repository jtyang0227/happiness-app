# 기획 — 메뉴 통합·고도화 (2026-10-20)

> 요청: "카테고리가 너무 많아, 합칠 수 있는 건 기능 합쳐서 고도화해줘"(헤더 스크린샷).
> 진행 기록: `WORK_QUEUE.md` 현재 묶음.

## 1. 진단 — 지금 헤더 10개가 실제로 하는 일

헤더에 없는 업무 화면(예약 `/bookings`, 납품 `/deliveries`)은 프로필 탭·URL로만 들어갈 수 있어 오히려 찾기 어렵다.

## 2. 새 구조

**탐색 · 내 작업 · 업무 · 모임** + 오른쪽 "＋ 올리기"(primary 버튼) + 아바타 메뉴(프로필 · 내 포트폴리오 보기 · 로그아웃).
제품 3단계(보여주기 → 일 받기 → 일 처리하기, MASTER_PLAN v2)에 맞춰: 탐색(남의 것 보기) · 내 작업(보여주기) · 업무(받은 일 처리) · 모임(커뮤니티).

### 2.1 탐색 = 갤러리 + 목록 + 탐색(사진) 통합 (고도화)
- 사진 탭 하나에 **검색·자동완성·최근 검색어**(기존 탐색) + **보기 방식 4종·색상순·사진 모달**(기존 갤러리)을 모은다.
- 정렬: 최신·오래된·좋아요·저장·조회·색상순(색상순은 불러온 사진 안에서 정렬 — 기존 갤러리와 같은 한계).
- 사진을 누르면 **모달**로 바로 본다(기존 갤러리 방식). 모달은 비로그인도 볼 수 있어, 로그인이 필요한 `/photo/:id`로 튕기던
  비로그인 탐색 문제도 함께 풀린다. 보기 방식은 기존처럼 브라우저에 기억(`gallery_view`).
- `/` → `/explore`, `/list` → `/explore`로 리다이렉트(북마크·외부 링크 보존). 로그인 직후 이동도 `/explore`.

### 2.2 내 작업 = 시리즈(작업 노트 관리) `/series`
- 메뉴 이름만 "내 작업"으로. 사진 올리기는 헤더 버튼으로 뺐다.

### 2.3 업무 = 문의·예약·일정·약속·납품 허브 (고도화)
- 새 화면 `/workspace` **"한눈에"**: 카드 5개(새 문의 · 예약 요청 · 미수금 · 납품 확인 대기 · 대기 중 약속, 숫자 + 바로가기) +
  **다가오는 7일 일정**(오늘 포함, 통합 달력과 같은 규칙: 확정 예약·확정 약속·예정/진행 중 모임).
- 기존 5개 화면(`/inbox` `/bookings` `/calendar` `/meets` `/deliveries`) 상단에 **같은 업무 탭**(한눈에 · 문의 · 예약 · 일정 · 약속 · 납품)을
  붙여 한 섹션처럼 오간다. 기존 URL은 그대로라 깨지는 링크 없음.
- 헤더 "업무" 배지 = 새 문의 + 대기 중 약속(기존 폴링 그대로 합산). 모임 배지는 모임 메뉴에 유지.
- 데이터는 기존 API를 `Promise.allSettled`로 병렬 호출(통합 달력과 같은 방식, 신규 백엔드 없음). 일부 실패해도 나머지는 보이고 실패한 항목만 "—"와 안내.

### 2.4 모바일 웹 하단 내비
탐색 · 내 작업 · ＋(올리기) · 업무 · 프로필.

## 3. 수용 기준
- AC-1 헤더 메뉴가 4개 + 올리기 버튼 + 아바타 메뉴로 줄고, 업무 하위 5개 화면에서 "업무"가 활성으로 보인다.
- AC-2 탐색 사진 탭에서 검색·장르·정렬(조회·색상 포함)·보기 방식 4종·더 보기·사진 모달이 모두 동작한다(비로그인 포함).
- AC-3 `/`·`/list` 접속 시 `/explore`로 이동한다.
- AC-4 `/workspace` 카드 숫자가 각 화면의 실제 데이터와 같고, 일정 7일 목록이 통합 달력과 같은 항목을 보여준다.
- AC-5 업무 5개 화면 상단 탭으로 서로 이동할 수 있다.

## 4. 트레이드오프
- 갤러리를 탐색에 흡수하면서 "갤러리" 단어가 메뉴에서 사라진다. 대신 탐색의 보기 방식 이름을 그대로 둬 익숙한 사용자는 같은 화면을 찾을 수 있다.
- 업무 허브는 화면 이동 없이 처리까지 하지는 않는다(카드 → 해당 화면). 한 화면에서 모든 처리를 하려면 각 화면 로직을 다시 짜야 해서 회귀 위험이 크다.
- 모바일 앱(React Native)의 탭 구조는 이번 범위 밖(이미 탐색·갤러리·등록·피드·프로필 5탭이고 업무 기능은 프로필 메뉴에 있음).
