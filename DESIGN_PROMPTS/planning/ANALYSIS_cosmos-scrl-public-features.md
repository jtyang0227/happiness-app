# ANALYSIS — Cosmos(모으기·탐색)·SCRL(편집) 공개 기능 대조 (2026-10-20)

> 요청: "4개 메뉴로 합쳤으니 안에서 개선할 부분을 기획해줘. Cosmos 앱과 대조해 기능을 찾고, 편집은 SCRL 앱과 대조해줘."
>
> **분석 한계**: 이 클라우드 환경의 네트워크 정책이 cosmos.so·scrl.com 같은 외부 사이트를 막고 있다. 그래서 REA로
> 실제 화면·번들을 분석하지 못했다(firecrawl scrape 403, 웹 검색 미사용). 아래 표는 **공개적으로 알려진 기능**을 기준으로
> 썼다. 세부 동작(정확한 내보내기 해상도, 유사도 알고리즘 등)은 실제 화면으로 확인하지 않았다. 앞의 Behance 분석과 같은 방식이다.

## 1. 앱 성격 비교

| | Cosmos | SCRL | Happiness(현재) |
|---|---|---|---|
| 핵심 | 이미지를 모으고 큐레이션하는 시각 탐색 앱. 좋아요 수를 보여 주지 않는 조용한 피드 | 인스타그램 캐러셀(가로로 이어지는 여러 장)·콜라주를 만드는 편집 앱 | 사진작가 포트폴리오 + 의뢰 업무 |
| 단위 | 요소(element) → 클러스터(cluster, 이름 붙은 묶음) | 캔버스 1개를 슬라이드 N장으로 자름 | 사진 → 작업(시리즈) / 보드 |
| 우리와 겹치는 메뉴 | 탐색, 내 작업(보드) | 편집(＋올리기 → 에디터) | |

## 2. Cosmos 공개 기능 ↔ 앱 현황

| Cosmos 기능(공개적으로 알려진 것) | 앱 현황 | 메뉴 | 판단 |
|---|---|---|---|
| 요소를 열면 **비슷한 이미지**가 이어서 나온다(시각 유사 탐색) | 사진 모달·상세에 "같은 작가 관련 사진"만 있음(`RelatedPhotos`). 작가를 가로지르는 유사 탐색 없음 | 탐색 | **P0** — 장르·색 분위기·대표색·비율 메타데이터 점수로 "비슷한 사진" |
| **색으로 검색**(팔레트·색감) | 서버 `colorMood` 필터는 있지만 탐색 UI에 노출 안 됨(색상 *정렬*만 있음) | 탐색 | **P0** — 색 분위기 칩 필터 |
| 의미 검색("붉은 노을 바다" 같은 자연어) | 제목·설명 pg_trgm 검색 | 탐색 | P2 — 임베딩이 필요해 비용·인프라 결정이 먼저 |
| 클러스터(이름 붙은 묶음)에 담기 | **있음** — 무드보드(비공개) | 내 작업 | 완료 |
| 클러스터 **공개·공유**, 남의 클러스터 팔로우 | 보드는 본인만 봄 | 내 작업 | **P0** — 보기 전용 공유 링크. 팔로우는 P2 |
| 남의 요소를 내 클러스터로 바로 담기 | 사진 모달 "📌 보드에" 있음 | 탐색 | 완료 |
| 클러스터 **공동 편집**(여러 명이 함께 모음) | 없음 | 모임·업무 | P1 — 모임 공동 보드, 의뢰인 레퍼런스 보드 |
| 좋아요 수를 숨긴 조용한 피드 | 카드에 ♡ 수 표시 | 탐색 | 보류 — 작가에겐 반응 수가 동기라 Behance 분석(감상·조회 공개)과 상충. 작가 설정으로 숨기기 옵션은 P2 |
| 무한 스크롤 그리드 | 웹은 "더 보기" 버튼, 모바일은 무한 스크롤 | 탐색 | P1 — 웹도 IntersectionObserver |
| 웹 클리퍼(브라우저 확장으로 외부 이미지 담기) | 없음 | 내 작업 | 제외 — 저작권·외부 이미지 저장 문제. 포트폴리오 앱 성격과 다름 |

## 3. SCRL 공개 기능 ↔ 에디터 현황

에디터(`ImageEditorPage`, `/photo/new`)는 보정(노출·HSL·커브·색 보정)·필터·변형·텍스트 오버레이·내보내기(JPG/PNG/WEBP,
원본/1080/2048)를 갖추고 있다. 사진 **한 장**을 다듬는 Lightroom 계열이다. SCRL은 **여러 장을 한 캔버스에 배치하고 슬라이드로
자르는** 레이아웃 도구다. 두 앱이 하는 일이 겹치지 않는다.

| SCRL 기능(공개적으로 알려진 것) | 에디터 현황 | 판단 |
|---|---|---|
| **가로로 이어지는 캔버스를 N장 슬라이드로 분할**(스와이프하면 이어지는 "심리스 캐러셀") | 없음 — 한 장씩만 내보냄 | **P0** — 내보내기 "캐러셀" 모드 |
| 슬라이드 비율 4:5(1080×1350)·1:1(1080×1080) | 크기만 고를 수 있고 비율 프리셋 없음 | **P0** — 캐러셀 모드에 포함 |
| 여러 사진을 한 캔버스에 이어 붙이기 | 에디터에 여러 장을 올릴 수는 있지만 각각 따로 내보냄 | **P0** — 올린 사진 전체를 한 줄로 이어 붙여 분할 |
| 여백(프레임)·배경색 | 없음 | **P0** — 여백 0~12%, 배경 흰색/검정/Toss 회색 |
| 레이아웃 템플릿(격자·비대칭 배치) | 없음 | P1 — 템플릿 3~4종(2분할·3분할·큰 1+작은 2) |
| 슬라이드별 텍스트·스티커 | 텍스트 오버레이는 사진 기준 1장 | P2 |
| 분할 미리보기(슬라이드 경계선) | — | **P0** — 내보내기 창에 경계선이 그려진 미리보기 |
| 슬라이드를 묶어 갤러리(작업)로 바로 올리기 | 단일 업로드만 | P1 — 분할 결과를 새 작업(시리즈)으로 업로드 |

## 4. 결론 — 이번 묶음 P0

1. **탐색**: 비슷한 사진(모달·상세) + 색 분위기 필터 칩
2. **내 작업**: 무드보드 보기 전용 공유 링크
3. **편집**: 캐러셀 분할 내보내기(비율·장 수·여백·배경색·이어 붙이기·미리보기)

P1·P2와 업무·모임 항목은 `PLANNING_inside-menus-upgrade.md`에 정리했다.
