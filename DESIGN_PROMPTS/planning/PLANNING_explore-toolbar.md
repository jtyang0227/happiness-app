# PLANNING — 탐색 사진 툴바 정리 (2026-10-20)

> 요청: 탐색 사진 탭 툴바 스크린샷 + "여기도 다른 앱 대조해서 개선해서 기획하고 개발해줘"
> 대조 기준: Unsplash·Pinterest·Behance·Cosmos의 **공개적으로 알려진** 탐색 화면 패턴. 이 환경에서는 외부 사이트가
> 네트워크 정책으로 막혀 실제 화면을 확인하지 못했다(앞선 분석서들과 같은 한계).

## 1. 진단 (모바일 390px 기준)

| 줄 | 지금 | 문제 |
|---|---|---|
| 1~3 | 정렬 칩 6개(최신·오래된·좋아요·저장·조회·색상)가 `flex-wrap`으로 3줄 | 한 번에 하나만 고르는 값인데 6개를 다 펼쳐 세로 공간을 가장 많이 쓴다 |
| 2 | 보기 방식 아이콘 4개(▦ ⊞ ☰ ⊟) + "9장" | 글리프 크기가 제각각이고 뜻을 알 수 없다(라벨·툴팁 영문 "Justified"/"Masonry") |
| 4 | 장르 탭(가로 스크롤) | 괜찮다 — 탐색의 1차 분류 |
| 5 | 색감 칩 12개(가로 스크롤) | 대부분 쓰지 않는데 늘 한 줄을 차지한다 |

사진이 시작되기 전까지 툴바가 약 280px — 첫 화면(844px)의 1/3이다.

## 2. 다른 앱 대조

| 앱 | 공개적으로 알려진 패턴 | 가져올 점 |
|---|---|---|
| Unsplash | 검색 결과 위 한 줄: 정렬 드롭다운("관련도/최신") + 방향·색 필터 드롭다운 | 하나만 고르는 값(정렬)은 **드롭다운 하나** |
| Pinterest | 상단 주제 칩 한 줄 가로 스크롤, 정렬 UI 없음 | 1차 분류(장르)만 **항상 보이는 한 줄** |
| Behance | "추천순 ▾" 정렬 + "필터" 버튼 → 펼침 패널, 적용된 필터는 태그로 표시·개별 해제 | 덜 쓰는 필터는 **접어 두고**, 적용 중일 때만 **요약 태그** |
| Cosmos | 검색창 중심, 색 필터는 검색 옆 작은 컨트롤 | 색감은 **버튼 하나로 열고 닫기** |

## 3. 개선안

1. **툴바 한 줄**(sticky 유지): `[정렬 ▾]` `[🎨 색감 ▾]` ……… `9장` `[보기 방식]`
   - 정렬: 네이티브 `<select>`를 pill 모양으로(키보드·스크린리더·모바일 휠 피커가 그대로 동작). 라벨 "정렬".
   - 색감: 버튼을 누르면 툴바 아래에 색 칩 줄이 펼쳐진다(`aria-expanded`). 고른 색이 있으면 버튼이 "● 따뜻함"으로 바뀐다.
   - 보기 방식: 아이콘 4개를 같은 크기(32×32)로, 한국어 이름(`aria-label`/`title`): 행 맞춤 · 벽돌 · 목록 · 매거진.
     모바일에서는 목록·매거진 차이가 작아도 기존 기억값(`gallery_view`)을 존중해 4개 모두 유지.
2. **장르 탭**: 그대로 한 줄.
3. **적용 중인 필터 요약 줄**(Behance): 검색어·장르·색감 중 하나라도 걸리면 툴바 아래 `"웨딩" ✕` `● 따뜻함 ✕` `검색: 노을 ✕` + "모두 지우기".
   걸린 게 없으면 줄 자체가 없다.
4. 결과 수는 툴바 오른쪽 `tabular-nums` 그대로.

결과: 필터가 없을 때 툴바 2줄(툴바 + 장르) ≈ 110px. 색감을 펼치거나 필터를 걸 때만 한 줄씩 는다.

## 4. 수용 기준

- AC-1 390px에서 필터 없음 상태의 툴바(검색창 제외)가 2줄이고, 가로 스크롤이 없다.
- AC-2 정렬 select로 6가지를 모두 고를 수 있고 결과가 바뀐다(색상순은 지금처럼 불러온 사진 안에서 정렬).
- AC-3 색감 버튼으로 칩 줄을 열고 닫을 수 있고, 고르면 URL `?mood=`·버튼 라벨·요약 줄에 반영된다. 요약 ✕로 풀 수 있다.
- AC-4 요약 줄의 "모두 지우기"가 검색어·장르·색감을 함께 지운다.
- AC-5 보기 방식 버튼은 같은 크기에 한국어 이름이 있고, 키보드 포커스가 보인다.

## 5. 트레이드오프

- 정렬을 드롭다운에 넣으면 지금 정렬이 무엇인지 한눈에 덜 보인다 → select 안에 현재 값이 항상 글자로 보이게 한다.
- 색감을 접으면 발견성이 떨어진다 → 버튼에 🎨 + "색감" 글자를 두고, 쓰는 중이면 색 점으로 바로 보인다.
- 백엔드 변경 없음.
