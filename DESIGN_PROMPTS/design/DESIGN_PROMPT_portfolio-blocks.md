## 요청

사진작가가 자기 포트폴리오 페이지를 블록으로 쌓아 만드는 편집 화면(1280px 데스크탑 + 390px 모바일)을 만들어 줘.

### 레이아웃
- 상단 바(흰색, 56px): "← 프로필" · 제목 "포트폴리오 구성" · 오른쪽 "공개 페이지 보기 ↗"(ghost) + "저장하고 공개"(primary, 변경 없으면 비활성, 저장 중 "저장 중…").
- 데스크탑: 왼쪽 패널 380px(흰 카드, 세로 스크롤) + 오른쪽 미리보기(회색 배경 위 실제 페이지, 상단에 "미리보기 · 데스크탑/모바일" 토글 — 모바일이면 390px 폭 프레임).
- 모바일: 패널이 위, 미리보기가 아래. 상단 바 버튼은 아이콘+짧은 글자.

### 왼쪽 패널 구성
1. **블록** 섹션 — 블록 행 목록. 행: 이모지 · 이름 · 요약(예: "사진 그리드 · 3열 12장") · 오른쪽 작은 버튼 ↑ ↓ 👁(숨김이면 🚫 + 행 흐리게) ⧉ ✕(✕는 danger 글자색, 누르면 확인). 선택된 행은 primaryLight 배경 + 왼쪽 primary 3px 선.
   아래 "＋ 블록 추가" 점선 버튼 → 카탈로그 시트(2열 카드: 이모지·이름·한 줄 설명).
2. **선택한 블록 설정** — 블록 종류에 맞는 입력란(제목·본문 textarea 글자 수·정렬 세그먼트·열 수 세그먼트 2/3/4·장 수 숫자·장르 select·체크박스).
3. **페이지 스타일** — 강조색 6개 원형 칩, 배경 3개(밝게·종이·어둡게) 세그먼트, 간격(좁게·보통·넓게), 제목 글꼴(고딕·명조).
4. 처음 열 때(블록 0개) — "어떤 페이지로 시작할까요?" 출발점 카드 3개(📁 작업 중심 · 💼 일 받기 중심 · 🖼 사진 중심).

### 블록(공개 페이지) 모양
- hero: 큰 이름(제목 글꼴) + 한 줄 소개 + 위치·전문 분야 + 문의/예약 버튼 + (선택) 사진·팔로워·좋아요 수. 정렬 left/center.
- photos: 제목 + 2~4열 정사각 그리드, 누르면 크게 보기.
- text: 640px 컬럼 제목+본문(줄바꿈 유지). quote: 큰 따옴표, 강조색 왼쪽 선, 작성자.
- contact: 카드 안 제목·설명·"촬영 문의하기"(강조색) + "예약 날짜 보기"(예약 받는 중일 때).
- 데이터가 없는 블록은 공개 페이지에서 사라지고, 미리보기에서만 점선 상자 "아직 고객 후기가 없어요 — 프로필 › 설정에서 추가".
