# DESIGN_PROMPT — 모바일 UI/UX 정리 (2026-10-21)

390px 웹 번들 + 로컬 백엔드(시드: 회원 2·사진 6·댓글)로 화면을 실제로 돌려 보며 찾은 문제와 고친 기준.

| 문제 (발견 화면) | 고친 기준 |
|---|---|
| 하단 탭 라벨이 한 글자씩 줄바꿈("둘러/보기", "프로/필") | 아이콘 칸 최소 폭 64, 라벨 한 줄, 비활성 라벨 `textSecondary`(흰 바탕 대비) |
| 헤더·탭바만 남색(#111417), 본문은 밝은 Toss 서페이스 | 흰 헤더·탭바 + 회색 구분선, 글자 `textPrimary`. 어두운 화면은 로그인 계열·슬라이드쇼만, 상태바 글자색도 이에 맞춤 |
| ＋ 버튼에 브랜드색 그림자 | 중립 그림자(검정 12%) |
| 갤러리 사진이 홀수면 마지막 카드가 한 줄 전체로 늘어남 | 빈 칸을 붙여 2열 폭 유지 |
| `FONT.xs` 미정의(33곳) → 배지·칩이 기본 크기 | `FONT.xs = 12` |
| 약속 상태 칩이 세로로 약 200px 늘어남 | 가로 ScrollView `flexGrow: 0`, 칩 가운데 정렬 |
| 예약 관리·납품 관리·통합 일정에 뒤로 가기 없음/노치 여백 없음(자체 헤더) | 공통 스택 헤더 사용, "⚙ 설정"은 헤더 오른쪽 |
| 약속 상세·가용 시간 설정·사진 상세의 자체 상단바가 노치 아래로 | safe-area 상단 여백 |
| 사진 상세에 작성자가 없음 | 제목 아래 아바타·이름·@프로필명 |
| "비슷한 사진" 제목이 화면 가장자리에 붙음 | 16px 여백, 사진 줄은 안쪽 여백으로 끝까지 스크롤 |
| 취소 버튼 흰 글자 + 연회색(대비 약 2.3:1) | 흰 바탕 + 테두리 + `textPrimary` 보조 버튼 |
| 시리즈 화면으로 가는 메뉴가 없음 | 프로필 메뉴 "📁 내 작업(시리즈)" |
| 차단 후 "사진 6장"인데 3장만 보임 | 숫자도 보이는 사진 기준 |

[시스템 컨텍스트]와 토큰은 `DESIGN_PROMPT_toss-design-system.md`와 같다 — Toss Blue `#3182F6` 단일 브랜드색, 배경 `#F2F4F6`, 카드 `#ffffff`, 구분선 `#E5E8EB`, 글자 `#191F28`/`#4E5968`/`#8B95A1`, 블러·브랜드 그림자 금지.
