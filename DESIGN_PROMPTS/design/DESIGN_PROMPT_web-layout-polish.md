# DESIGN_PROMPT — 웹 화면 깨짐·위치 정리 (2026-10-21)

로컬 백엔드 + 시드(회원 2·사진 8·시리즈 2·모임·약속·예약·문의) + 운영 빌드로 21개 화면을 390px·1280px에서 캡처하고,
가로 넘침(문서 너비 > 창 너비)을 스크립트로 자동 검사해 찾은 문제와 고친 기준. [시스템 컨텍스트]·토큰은
`DESIGN_PROMPT_toss-design-system.md`와 같다.

| 문제 (화면) | 고친 기준 |
|---|---|
| 사진 상세 390px 가로 스크롤(410>390), 이전/다음 화살표가 화면 밖·사진 패널에 반쯤 잘림 | 화살표를 사진 영역 안쪽 12px |
| 사진 상세 액션 버튼 "보드에 담기"가 잘림 | 버튼이 글자 폭 이하로 줄지 않고 다음 줄로 |
| 대표 색상 칩: 흰색 칩이 배경에 묻혀 글자만 보임, 같은 색 중복 key | 1px 안쪽 테두리(호버 후에도 유지), index key |
| 업무 탭 줄은 왼쪽, 아래 화면은 가운데 정렬(데스크탑) | 탭 줄 가운데 정렬, 넘치면 왼쪽부터 가로 스크롤 |
| 데스크탑 로그인 왼쪽 모자이크가 빈 회색 상자 3개 | 최근 공개 사진 3장으로 채움(실패 시 빈 프레임) |
| 사진 모임 머리말: 설명이 버튼 옆에 3줄로 눌림(390px) | 좁으면 버튼이 아래 줄로 |
| 시리즈 머리말: "+ 새 시리즈"·"보기" 버튼이 두 줄로 깨짐, 공개 주소 상자 눌림, 오타 "컴렝션" | 버튼 줄바꿈 금지, 주소 상자 줄바꿈 허용·주소 말줄임, "컬렉션" |
| 모임 해시태그가 "#노을,한강" 한 칩 | 공백·콤마로 나눠 칩 여러 개 |
| 포트폴리오(Editorial) 컬렉션 카드가 왼쪽, 위 제목·필터는 가운데 | 카드 줄 가운데, 넘치면 스크롤 |

확인했지만 그대로 둔 것: 로고 `hpns` 모양(실제 브랜드 마크 이미지), Editorial 히어로의 큰 이니셜(의도된 고스트 타이포), 포트폴리오 무드 필터 바 왼쪽 정렬(스티키 필터 바 관례).
