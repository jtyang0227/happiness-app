# DESIGN_PROMPT — 모바일 웹 하단 탭: 아이콘 전용 + 설정 기반 (2026-10-22)

요청: "밑에 둘러보기나, 내 작업, 업무, 프로필 이라는 글자 말고 아이콘으로 변경해주고 ui 더 확장성 있게 수정해줘"

## 문제
- 탭마다 유니코드 기호(⊙ ✦ ▤ ◎) + 9px 글자. 기호가 뜻을 전달하지 못해 글자에 기대고 있었고, 9px 글자는 읽기도 어렵다.
- 탭 목록·배지가 컴포넌트 안에 박혀 있어 탭을 바꾸려면 렌더 코드를 고쳐야 한다. 비로그인에도 "내 작업·업무·프로필"이 보여 눌러야 로그인 화면으로 튕긴다.

## 결정
- **아이콘만**(글자 없음): 뜻이 분명한 선 아이콘 — 둘러보기=나침반, 내 작업=겹친 사진, 올리기=＋(가운데 원), 업무=서류가방, 프로필=사람, 모임=두 사람, 로그인=문 화살표.
  이모지는 기기마다 모양·색이 달라 활성/비활성 색을 줄 수 없어서, 외부 라이브러리 없이 **인라인 SVG**(24px, 선 1.8)로 그린다. 활성은 브랜드 블루 + 면 채움 느낌(선 2.2), 비활성은 textMuted.
- **접근성**: 글자가 없으니 각 탭에 `aria-label`(배지 수 포함, 예: "업무, 처리할 일 3건")·`title`, 현재 탭은 `aria-current="page"`. 터치 영역은 탭 칸 전체(최소 48×48).
- **확장성**: 탭은 `components/layout/navConfig.js`의 배열 한 곳에서 정의 — `{ to, label, icon, auth, guestOnly, match, badge, isCenter }`. 아이콘은 `NavIcon`의 이름 레지스트리, 배지는 `badges` 객체(`{ workspace: n, gatherings: n }`)로 넘겨 새 배지 종류도 설정에서 이름만 지정. 탭 수가 바뀌어도 균등 분할.
- 비로그인: 둘러보기 · 모임 · 로그인 3탭.

```
[시스템 컨텍스트]
앱 이름: Happiness — 포트폴리오 사진 갤러리 앱
기술 스택: React 18 SPA, React Router v6, inline style (CSS-in-JS 없음)
아이콘: 이모지 또는 유니코드 기호 사용 (외부 아이콘 라이브러리 없음) — 이 화면은 인라인 SVG 예외

현재 컬러 시스템 (Toss 디자인 시스템, 2026-08-29~):
  primary: '#3182F6'  primaryLight: '#E8F3FF'  bg: '#F2F4F6'  surface: '#ffffff'
  border: '#E5E8EB'  text: '#191F28'  textMuted: '#8B95A1'  danger: '#F04452'

규칙:
- export default 함수형 컴포넌트 1개만 반환, style은 inline object, 외부 라이브러리 import 없음
- backdrop-filter/blur·컬러 그림자 금지, 그림자는 중립 회색만
```

390px 화면 하단에 떠 있는 둥근 탭 바(좌우 12px, 높이 60, 흰색, 회색 그림자)를 만들어 줘. 아이콘 5개(나침반·겹친 사진·가운데 파란 원 ＋·서류가방·사람)만, 글자 없음.
활성 탭은 아이콘이 파란색 + 아이콘 위 2px×20px 파란 막대, 업무 아이콘 오른쪽 위에 빨간 숫자 배지.
누르면 scale(0.92) 피드백, focus-visible 파란 링.

## 2차 (2026-10-22) — Cosmos·Instagram 하단 바 참고

요청: "아이콘 ui 참고해서 다시 작업해줘" (Cosmos 앱·Instagram 하단 바 스크린샷 첨부)

참고한 점
- **Cosmos**: 어두운 알약 바 + 굵은 선 아이콘, 활성 아이콘은 **면 채움(흰색)**, 주요 행동(검색)은 **알약 밖 별도 원형 버튼**.
- **Instagram**: 어두운 알약 바, 굵은 선 아이콘, 마지막 탭은 **내 프로필 사진**, 활성 탭은 **둥근 캡슐 배경**으로 표시.

결정
- 바: 단색 다크 알약(`text` #191F28) — 참고 화면의 반투명 유리(blur)는 Toss 플랫 규칙상 쓰지 않고 **불투명 단색 + 회색 그림자**로 대체(유일한 차이).
- 아이콘: 선 2.0(이전 1.8)으로 굵게, 비활성 흰색 62% 불투명, **활성은 면 채움 아이콘(흰색) + 흰 10% 캡슐 배경**(48×40, radius 999). 위쪽 파란 막대는 없앰.
- 프로필 탭: 로그인 회원의 `avatarUrl` 원형 사진(26px). 없으면 이름 첫 글자 원, 활성이면 흰 2px 링.
- 올리기(＋): 알약 밖 오른쪽 56px 브랜드 블루 원(Cosmos 검색 원 위치). 비로그인은 원 없이 알약만(둘러보기·모임·로그인).
- 배지: danger, 테두리는 바 색과 같게 해 아이콘과 분리.
- 접근성 유지: `aria-label`(배지 수)·`title`·`aria-current`, 탭 칸 최소 48px, 누름 scale(0.92), focus-visible 흰 링, reduced-motion 시 전환 없음.

```
390px 화면 하단에 떠 있는 어두운 알약 바(#191F28, 높이 60, 좌 12px, 우측은 56px 파란 원 버튼 + 8px 간격).
알약 안: 나침반·겹친 사진·서류가방·내 프로필 사진(원형) 4칸, 글자 없음. 활성 탭은 흰 면 채움 아이콘 + 반투명 흰 캡슐 배경.
blur 금지, 그림자는 rgba(0,0,0,0.18) 중립 회색.
```
