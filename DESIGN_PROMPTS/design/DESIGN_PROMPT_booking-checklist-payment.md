## BookingDashboard — CONFIRMED 예약 카드 확장

```
┌─────────────────────────────────────────────────┐
│ 📷 스냅   🚚 납품 임박                              │
│ 📅 2026.09.20 · 14:00                             │
│ 👤 김민지                                           │
│ 📞 010-1234-5678                                  │
├─────────────────────────────────────────────────┤
│ [취소]                                             │
├─────────────────────────────────────────────────┤
│ ✅ 촬영 준비 체크리스트 (2/4)          펼치기 ▼      │
│  (펼친 상태)                                        │
│  ☑ 카메라 바디                                  ×  │
│  ☑ 렌즈 2종                                     ×  │
│  ☐ 조명 장비                                    ×  │
│  ☐ 소품                                         ×  │
│  [준비물 추가__________] [+ 추가]                  │
│  납품 기한 [2026-09-27]                            │
├─────────────────────────────────────────────────┤
│ 💰 수금 현황                                        │
│  계약금  [✓ 수령 완료]  [금액(선택)__] 원            │
│  잔금    [미수령]      [금액(선택)__] 원            │
│                                    [금액 저장]      │
└─────────────────────────────────────────────────┘
```

- 체크리스트는 아코디언(기본 접힘), 완료 개수(n/m) 헤더에 표시
- 항목 추가/체크/삭제/납품기한 변경 시 즉시 `PUT /api/booking/{id}/checklist` 자동 저장
- 납품 기한이 오늘로부터 3일 이내면 카드 제목 옆에 주황색 "🚚 납품 임박" 배지(컴팩트 리스트·풀 카드·상세 패널 전부 동일 규칙)
- 수금 토글 버튼: 미수령(회색 아웃라인) ↔ 수령 완료(초록 톤 배경), 클릭 즉시 `PUT /api/booking/{id}/payment` 저장(계약금/잔금 각각 독립 토글)
- 금액 입력은 선택 사항 — 비워도 토글은 정상 동작(AC-c5)
- 상단 탭에 "미수금" 탭 추가 — CONFIRMED 예약 중 depositStatus 또는 balanceStatus가 PENDING인 것만 표시, 이 탭에서 수령 완료로 토글하면 그 예약은 목록에서 즉시 사라짐(자연스러운 처리 완료 피드백)
- 월간 수금 요약 카드는 P2(별도 `GET /api/booking/payment-summary` 필요, 이번 스코프 아님)
