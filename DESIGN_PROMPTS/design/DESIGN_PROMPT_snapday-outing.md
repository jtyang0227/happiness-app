## 1. 출사 투표 달력 (`/gatherings/polls/:id`)
"2027년 3월 출사 투표" 화면을 만들어 줘.
- 상단: 제목, 상태 칩(투표 중 파랑 / 마감 회색 / 확정 초록 `successText`), 마감까지 남은 시간, 응답자 수.
- 월 달력 7열(일~토). 일요일·공휴일 숫자 `danger`, 토요일 `primary`. 후보 날짜만 누를 수 있고, 후보가 아닌 날은 `textMuted`.
- 후보 날짜 셀: 숫자 + 공휴일 이름(작게) + 아래 "가능 n" 칩. 내 응답 가능 = 연초록 배경(#E8F7EF) + ✓, 불가 = 회색 배경 + ✕, 미응답 = 흰 배경 점선 테두리. 추천 날짜 = 위 오른쪽 ★, 확정일 = 블루 채움 + 흰 글자.
- 날짜를 누르면 아래 시트: "가능 / 불가 / 응답 지우기" 세 버튼(공통 Button), 그 날 가능·불가 인원 막대.
- 달력 아래 "날짜별 집계" 목록: 날짜·요일·가능 인원 막대(최다는 블루), 최소 인원 선.
- 관리자 도구(관리자만): 평일 추가(date input), 마감/다시 열기, 미응답 리마인드, 확정(날짜 고르고 제목·장소·시작/종료 시각·정원 입력 → 이중 확인).
- 상태: 스켈레톤(달력 격자 회색 블록), 후보 없음 빈 상태, 비로그인 "로그인하고 응답하기".
- 390px: 셀 44px 이상(터치), 1280px: 달력 왼쪽·집계 오른쪽 2단.

## 2. 출사 투표 목록 (`/gatherings/polls`)
2027년 1~12월 카드 그리드(모바일 2열, 데스크탑 4열). 카드: "3월", 상태(투표 없음 회색 점선 / 투표 중 / 마감 / 확정 날짜). 관리자는 "투표 없음" 카드에 "투표 만들기". 상단에 연도 좌우 이동, 관리자 "공휴일 관리".

## 3. AI 출사 추천 (모임 상세 섹션)
- 헤더 "🤖 AI 출사 추천" + 출처 배지(AI = primaryLight, 샘플 = 주황 톤 "샘플 — 실제 장소 아님").
- 요약 문단 → 장소 카드(가로 스크롤 또는 세로 목록): 장소명, 지역, 추천 이유, 🕐 추천 시간, 📸 촬영 포인트 칩, 콘셉트, ☔ 우천 대안, "카카오맵에서 찾기" 링크, (만든 사람) "장소 투표 후보로".
- 🍜 제철 음식 칩, 교통·주차 안내, 주의 문구 회색 박스 "AI가 만든 정보예요. 주소·영업시간·날씨·개화는 방문 전 꼭 확인해 주세요."
- 하단: 추가 질문 입력 + "다시 추천받기", 이전 추천 기록 접기.

## 4. 현장 모드 (모임 상세)
진행 중 배너: "🔴 출사 진행 중 — 사진을 올려 주세요"(빨강 점은 danger, 배경 흰색), 만든 사람에게 "출사 종료" 버튼(이중 확인). 시작 전: "출사 시작" 버튼(primary).

## 5. 베스트 포토 (앨범)
상단 "🏆 베스트 포토 투표 — 내 표 n/3". 사진 카드 오른쪽 아래 하트형 투표 버튼(선택 시 블루), 득표 수. 순위 1~3위는 🥇🥈🥉 배지. 정렬 탭 최신/인기, 회원 필터 셀렉트.

## 6. 스토리 편집기 (`/gatherings/:id/story`, 에디터라 중립 다크 예외)
- 배경 `darkBg`, 가운데 9:16 미리보기(모바일 화면 높이에 맞춤), 아래 도구 탭: 사진 · 레이아웃 · 텍스트 · 스티커 · 태그.
- 사진: 모임 사진 썸네일 줄 + "내 기기에서", 최대 3장. 레이아웃: 1장 꽉 채움 / 2장 위아래 / 3장(1+2). 배경색 6개.
- 텍스트: 추가 → 미리보기에서 끌어 옮기기, 크기 슬라이더, 흰/검정. 스티커: 📅 날짜, 📍 위치, 출사명.
- 태그: 참여자 체크 목록(@instagramId), 미리보기 "@a @b", "태그 전체 복사".
- 하단 고정: "이미지 저장"(secondary) · "공유하기"(primary) · "스토리 올리기". 인스타그램 안내: "인스타그램 앱에서 태그 문구를 붙여 넣어 주세요(자동 멘션은 지원되지 않아요)".

## 7. 베스트 포토 순위 (`/gatherings/best`, 2026-11-25 추가)
- 머리말: "← 모임으로", 제목 "🏆 베스트 포토", 부제 "출사에서 표를 가장 많이 받은 사진". 오른쪽 "월간 | 연간" 세그먼트 + 연도 ‹ 2026년 ›.
- 월간이면 아래 1~12월 칩 한 줄(가로 스크롤, 고른 달은 블루 채움). 기본값은 이번 달.
- 카드 격자 4/3/2열: 정사각 사진(1~3위는 왼쪽 위 🥇🥈🥉, 그 외 "n위" 흰 알약), 아래 "🗳 n표 · 이름", 출사명(한 줄 말줄임) — 카드를 누르면 그 출사 앨범.
- 동점은 같은 순위. 로딩은 회색 정사각 스켈레톤 8개, 비면 "이 기간에 끝난 출사의 베스트 포토가 아직 없어요" + "출사 투표 보기".
- 진입점: 모임 목록 머리말 "🏆 베스트" 버튼, 앨범의 베스트 포토 섹션 "이달의 베스트 보기 →".
